# Domain docs

AgentSession uses a single-context domain layout.

## Before exploring

- Read root `GLOSSARY.md` when it exists.
- Read `docs/decisions/README.md` and ADRs relevant to the work.

If the glossary is absent, proceed silently. Create it through
domain-modeling only when the first domain term is resolved.

## Recording terms and decisions

Use glossary terms consistently in issues, proposals, code, and tests.
When a needed term is missing, reconsider the wording or flag the gap
for domain-modeling.

Record ADRs in the existing `docs/decisions/` directory. Follow its
`README.md` and `TEMPLATE.md`, including numbering, statuses, and
register updates.

Surface conflicts with accepted ADRs explicitly, identifying the decision
and explaining why it should be reopened.
